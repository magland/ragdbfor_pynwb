# Conversion Gallery

## Overview
This document catalogs examples for converting various neurophysiology data formats to NWB using pynwb via the NeuroConv library. The examples demonstrate how to convert data from different recording modalities and formats.

## Electrophysiology

### Extracellular Recording
Formats supported:
- AlphaOmega
- Axona
- Biocam
- Blackrock
- European Data Format (EDF)
- Intan
- MaxOne
- MCSRaw
- MEArec
- Neuralynx
- NeuroScope
- OpenEphys
- Plexon/Plexon2
- Spike2
- Spikegadgets
- SpikeGLX
- Tucker-Davis Technologies (TDT)

### Spike Sorting
Formats supported:
- Blackrock
- Cell Explorer
- KiloSort
- Neuralynx
- NeuroScope
- Phy
- Plexon

### Intracellular Electrophysiology
- ABF (Axon Binary Format)

## Optical Physiology

### Imaging
Formats supported:
- Bruker
- HDF5
- Micro-Manager
- Miniscope
- Scanbox
- ScanImage
- Thor
- Tiff

### Segmentation
Formats supported:
- Caiman
- CNMFE
- EXTRACT
- Suite2P

### Fiber Photometry
- TDT Fiber Photometry

## Behavior
Formats supported:
- Audio
- DeepLabCut
- FicTrac
- LightningPose
- Neuralynx NVT
- SLEAP
- Videos
- MedPC

## Other Data Types
- Images (png, jpeg, tiff)
- Text (CSV, Excel)

## Common Interface Combinations
- SpikeGLX and Phy
- Tiff and Suite2p
- Ecephys and pose estimation

Users can request new formats or build custom data interfaces if needed.
